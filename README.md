# 妇幼保健院随访管理系统

内网 B/S 随访作业台账：科室导 Excel，医护在浏览器里做随访、改状态。权限按人切数据，看板只读聚合。不接 His、不接外网、不发短信。

栈：Vue 3 + NestJS + PostgreSQL。一台内网机器，Docker Compose 三容器即可。

## 启动

```bash
docker compose up --build
```

打开 http://localhost:8080

演示账号密码均为 `admin123`：

| 登录名 | 角色 | 数据范围 |
| --- | --- | --- |
| admin | 系统管理员 | 全院 |
| dept01 | 科室管理员（产科） | 本科室 |
| nurse01 | 普通医护（产科） | 本人负责的任务 |

首次启动会建表并写入演示数据（科室、人员、随访任务）。库已有人员则不再灌种子。

## 随访导入模板列

姓名, 联系电话, 计划随访日期, 随访责任人, 备注, 随访类型, 所属科室

- 必填：姓名、联系电话、计划随访日期
- 责任人可空，默认导入人；科室可空，默认导入人科室；类型可空，默认「常规」
- v1 不采集病案号。增量键：规范化电话 + 姓名 + 计划日期
- 已随访跳过，不覆盖结果；待随访 / 已逾期则更新备注、责任人、类型
- 同一文件内重复键直接失败该行，不静默合并
- 单次最多 5000 行

人员模板：姓名, 工号, 登录名, 所属科室, 角色（普通医护 / 科室管理员 / 系统管理员）。初始密码 `admin123`。

## 任务状态

系统计算，导入不能手写状态：

- 待随访：计划日未过
- 已逾期：计划日已过仍未完成（每小时扫描，每天 08:00 再扫一次）
- 已随访：填写结果后锁定，导入不再覆盖

登录后右上角角标提醒：逾期 + 今日待随访。不做弹窗、不做短信。

## 权限

查询、导出、看板、完成随访共用同一套范围：

- 普通医护：`owner_id = 自己`
- 科室管理员：`dept_id = 本科室`
- 系统管理员：不过滤

## 溯源（v1 最小集）

- 每次导入：文件名、操作人、成功 / 跳过 / 失败原因（行级）
- 完成随访：谁在何时把状态改成已随访，并留下结果摘要
- 不做全字段变更史

## 页面

- 首页看板：总量、待/已随访、完成率；孕产妇走势、儿童状态、科室排行、今日待办
- 随访任务：组合检索、完成并锁定、导出、任务事件
- 数据导入：下载模板、上传、对账报告
- 统计分析：日期范围内的状态占比与科室工作量
- 系统管理：科室人员导入、导入留痕

## 本地开发（可选）

先起数据库：`docker compose up -d postgres`，然后：

```bash
cd apps/api
npm install
npx prisma generate
npx prisma db push
npm run start:dev

cd apps/web
npm install
npm run dev
```

前端开发服务在 http://localhost:8080，`/api` 代理到 3000。
